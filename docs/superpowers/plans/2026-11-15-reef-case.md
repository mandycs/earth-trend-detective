# Great Barrier Reef — fourth solved case Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `sites/great_barrier_reef/` as the fourth story-mode case (sea temperature warming everywhere, heat-stress years going from rare to almost yearly, chlorophyll "not detected"), built by one reproducible, cached command and listed by the backend (`load_sites`, `solved_case`) and the front (`/story/great_barrier_reef`).

**Architecture:** A self-contained `backend/app/reef/` package does the sea-specific work the land pipeline cannot: it reads cached ERDDAP data one year per call (MUR grid through the data-tools `fetch_grid`, chlorophyll through `fetch_point_monthly`, DHW and GEBCO through its own encoded-bracket CSV requests), turns them into the existing asset contract (reusing `assets/maps.write_variable_maps`, `assets/relief`, `assets/dem.to_png16`, `assets/gibs.fetch_base_image`), and writes `site.json` through `site_export.build_site_json` with a reef gather function, then post-processes it (DHW event row, heat-stress block, sea caveats, sources). Sites get a `pipeline: land | sea` field so every generic land tool skips the reef.

**Tech Stack:** Python 3.12 (backend venv), httpx, numpy, pandas, xarray, Pillow, matplotlib, pytest; Next 16.4 / React 19.3 front (no version changes).

**Spec:** `docs/superpowers/specs/2026-11-15-detective-agent-design.md` §5.5c (fourth case) and §5.5d (map = evidence). Binding facts: `.superpowers/reef-scout-2026-11-15.md`. Contract: `frontend/README.md`, `frontend/src/story/types.ts`, `AGENTS.md`.

**Depends on:** `docs/superpowers/plans/2026-11-15-detective-data-tools.md` **Task 1 merged** (`backend/app/extractors/erddap.py` with `fetch_point_monthly` and `fetch_grid`; `gather.SOURCES["erddap"]` / `gather.FETCHERS["erddap"]`; catalog variables `sst`, `chlorophyll`, `dhw`; `"erddap"` accepted by `catalog.SOURCES`). - ERDDAP access: brackets URL-encoded (`%5B` `%5D`); one year per request; requests strictly sequential (parallel → 408); DHW per point per year **January–June only** (whole year → 502); retry 502/503/408 up to 3 times with a 5 s pause; never cache an error.
- Study period 2003–2024 (`sites.yaml` `study_period`). Thresholds: NOAA Coral Reef Watch 4 and 8 °C-weeks, "at or above" (≥).
- Site box = the scout's central box: `bbox: [145.5, -21.0, 150.0, -17.0]`, `point: [147.6, -18.8]` (Davies Reef). MUR grid stride 5; GEBCO stride 2.
- Reef points (id, name, lat, lon): `north` "Northern reef (off Cooktown)" −14.6, 145.6; `davies` "Davies Reef (central)" −18.8, 147.6; `outer` "Outer shelf (central)" −18.3, 148.3; `burdekin` "Inshore, off the Burdekin River" −19.45, 147.75; `heron` "Heron Reef (south)" −23.4, 152.0.
- **Decision — no climate split.** Sea temperature is itself a climate variable and no tested driver stands for a local human signal in open water; spec §5.5c frames "is it the climate" as heat (DHW) plus a water-quality clue, never a residual. `residual_pct_non_climate` and `residual_pct_range` are null for every reef row, and the first caveat says why.
- **Decision — DHW is an event record, not a trend test.** It is not put through Mann-Kendall or the FDR family; its row has `kind: "events"`, null slope/p/q, and counts of reef-years at or above each threshold in the two halves of the study period (2003–2013, 2014–2024), computed by code. The split is the period midpoint, not a year chosen from the data.
- Stack fixed: no dependency upgrades, front or back.

## Review Focus

1. **ERDDAP grids come latitude-ascending** (south first) while every PNG and `crop_to_bbox` expect rows north → south: maps would render upside down with no error. Test `test_mur_grid_rows_run_north_to_south` (Task 3), `test_gebco_rows_run_north_to_south` (Task 6).

3. **A masked or missing DHW cell/year read as 0 °C-weeks** would under-count heat stress and still look like a measurement. A NaN year must be `null`, excluded from counts, and counted in `reef_years_missing`. Test `test_missing_year_is_null_not_zero` (Task 4).
